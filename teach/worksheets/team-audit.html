Find where delivery chokes once agents write the code

When agents make code cheap, the wait moves to review, verification and release. DORA's 2025 report found that AI amplifies the system it lands in. Run this with the team in the room.

1Where are you today?

Take the last 30 days: pull requests merged per week, wait for first review, lead time to production, reverts and hotfixes, share written mostly by an agent, and agent spend per pull request. Write "unknown" where you cannot pull a number. That is a finding too.

2Score each layer from 0 to 3

0 means none, 1 ad hoc, 2 written down and 3 enforced by a check. Write the evidence beside each score.

LayerA 3 looks likeScoreEvidence
IntakeA ticket has a ready checklist an agent can check
TriageEach ticket type has its own route and risk tier
PlanningFeatures carry a spec a person approves before code
ContextA short AGENTS.md, path rules and skills in the repo
IsolationAgents run in a worktree or sandbox with limits
VerificationGates and holdout tests the agent cannot skip
ReviewRisk tiers decide approvals, with a cap on rounds
DeliveryMerge queue, feature flags, staged release and fast rollback
LearningIncidents become evals and repeated comments become rules
MeasurementWait time, rounds and cost per pull request on a dashboard
GovernanceA written AI policy, spend limits and an audit trail per run

3Which three layers will you fix first?

Pick low scores that block the most work. For each, say what it blocks today, the first change, its owner and the check that proves it worked.

4What will be true at 30, 60 and 90 days?

A common path: one ticket type automated by day 30, risk tiers and agent review by day 60, and a guardrail number by day 90.

Questions to ask in the room

  • Which pull requests would you merge without reading the diff if the evidence were attached? What evidence?
  • Which paths must always have a person, whoever wrote the change?
  • What did the last three incidents have in common, and would a gate have caught one?
  • Who owns a change an agent wrote, and who answers for it when it breaks?
