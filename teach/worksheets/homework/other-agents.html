Assignment 4

The loop is the product, the agent is a part

The gate, plan approval and the verdict do not depend on which coding agent runs a stage. That is why the same factory can run Claude for build and another vendor for verify, and why other teams' factories draw the human line in nearly the same places.

1One loop, any agent per stage

{
  "agents": { "claude": { "preset": "claude" }, "gemini": { "preset": "gemini" } },
  "stages": { "default": "claude", "verify": "gemini" }
}

From the factory's docs/agents.md. factory install <repo> --agents claude,gemini keeps skills in .claude/skills and symlinks the other agents' skill folders to it.

What they all agree on
A human approves scope before code, and a human merges. Two revision rounds is a common cap (Foreman and ours).
Where we differ
Our verify must revert the fix and see the test fail, holdout tests are hidden from every agent, and the runner trusts only the gate's own line, never the agent's claim.

Assignment: pick the stage where a second vendor would help you most. For us it is verify on lwp-academy copy and redirect cards, where a read-only flag is enough and a different model catches what the builder missed.
