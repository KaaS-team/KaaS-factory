Assignment 1

The .claude directory, in three layers

Context has an owner. What is true for you goes in your home folder, what is true for the team goes in a plugin, and what is true for one repo goes in that repo. A factory agent runs with only the repo layer, so anything it needs must live there.

Find one line outside the repo that a factory run would need. Move it.
"Operator detail never reaches a customer" lived in the team standard, engineering.md in lwp-eng. The factory broke it anyway (#44, spend on tracker cards), because a runner does not read a plugin. It is now code in the runner (PR #48), and englishmaa's AGENTS.md states it for that repo.
Which repo of yours cannot run without your home folder?
kaas.team and lwp-academy. Their hooks only work through plugins enabled on Param's machine; neither has a repo.json, so the repo-driven guards have nothing to read in a factory worktree.
Pick one rule that should be path-scoped instead of always loaded.
"Every Plunk call names subscribe or not" belongs in a rule scoped to lead.mjs, not in AGENTS.md, so it costs nothing on a book revision.
What enforces it when the model ignores the rule?
A hook for actions (guard-protected-paths refuses the edit), a test for outcomes (the lead-kind walk). A rule with neither is a wish.
