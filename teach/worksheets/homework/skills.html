Skills that hold up, and when a skill must become a gate

A skill tells the agent how. A gate proves it happened. We learned this the slow way: several of our skills graded their own output, and the grade said pass while the work was wrong. Every one of those self-graded rubrics has since been replaced by a check a script runs.

3Vendoring upstream skills safely

We do not install upstream skills live. plugins/lwp-eng/vendor.json pins each source to a commit and each file to a sha256, so an upstream change cannot reach a factory run until someone reads it and bumps the pin.

"addyosmani/agent-skills": { "commit": "1401c8b8…", "license": "MIT" }
"code-review-and-quality": {
  "path": "skills/code-review-and-quality",
  "files": { "SKILL.md": "2db1e850…", "LICENSE": "6f202f8b…" }
}
