Our own Software Factory homework, on three real businesses

These are the worksheets filled in for the products we run ourselves: kaas.team, lwp-academy and englishmaa.com. Each page maps today's real path from the git history, then redesigns it as factory workflows. The factory's own release loop and an overnight run on kaas-suite are the evidence that the redesign is not theory.

The loop every page maps onto

Yellow is a human in the loop. Green is a check a script runs. The red dashed line is verify sending work back to build, at most twice, before the card parks for a human.
