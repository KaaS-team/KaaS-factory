## Issues

### #596 Declared CLI tools and a cli step

## Problem

A workflow can only call built-in steps. A repo cannot declare its own command-line tool and call it as a step.

## Acceptance

- A config lists CLI tools by name, command and expected output.
- A `cli` step runs a declared tool and records its output.
- An undeclared tool is refused with its name.
- A test covers a declared tool, an undeclared one and a failing command.

## Out of scope

- Tools reached through MCP.

Blocked by: #587

### #597 Generic tracker over MCP, with a probe command and example mappings

## Problem

Trackers such as Jira, Linear and Plane each need code. A generic tracker driven by a mapping file over MCP would cover them with config.

## Acceptance

- A mapping file says how to list, read and update issues through an MCP server.
- `factory tools` probes a configured server and reports which mapped calls work.
- Example mappings ship for three trackers.
- A fake MCP server in tests drives list, read and update through the mapping.

## Out of scope

- Writing a new adapter for any tracker.

Blocked by: #596

## Out of scope
