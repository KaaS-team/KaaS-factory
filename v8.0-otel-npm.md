## Rules

## Issues

### #608 Audit events leave as OpenTelemetry spans

## Problem

Audit events stay in the factory's own log, so a company cannot see them in the tools it already uses.

## Acceptance

- Each audit event produces one span with the event type, actor and issue.
- A fixture exporter in tests receives one span per event.
- With no exporter configured, nothing changes.

## Out of scope

- Choosing a vendor.

### #614 npm wrapper that installs the released binary

## Problem

Installing needs a download and a path edit. `npx` or `npm i -g` is what most teams reach for first.

## Acceptance

- The npm package downloads the release binary for the platform and checks its checksum.
- A wrong checksum fails the install and names the file.
- A test covers a good and a bad checksum.

## Out of scope

- Publishing: the token is an owner step (#276).
