## Learnings
- No `just` in the cloud image: the ticket's fallback list worked, but the factory image should ship it.
- golangci-lint v2.13.2 needs go 1.26 and GOTOOLCHAIN=auto switched silently; say so in the setup step.
- `git merge-tree` exits 1 for a bad ref as well as for conflicts; check for the tree id on stdout before reading conflicts.
- A race-only CAS test passes even with plain --force when git's ref lock rejects one pusher; add a deterministic stale-taker step to every CAS test.
- Heredocs turned an escaped U+2028 into a literal character in Go source; write such code through an escape-aware tool and test it.
