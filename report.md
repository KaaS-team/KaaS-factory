## Learnings
- `make fast` takes 3 to 8 minutes once scripts/ or src/ change, because every touched file selects mutations; it passes the 120 s tool limit. Run it in the background.
- The tests-only check rejects `.toBeUndefined()`, `.toBeTruthy()` and similar in new test files; use an exact comparison.
- `bun test` runs no exit handler from a preload, and `afterAll` cannot tell the last rerun, so cleanup needs a watcher process.
- Moving code out of a file can orphan legacy entries in tests/mutations.json; `bun scripts/check-mutation-anchors.ts` names them.
- Several tests set `body` directly; any new plan-time rule on issue bodies breaks them. Test fixtures need a shared body helper.
- Biome's `--write` on a whole directory touches nothing outside the files it fixes, but `biome ci` prints many infos; use `--diagnostic-level=error` to find the failing file.
- The brief says the lease test takes an injected clock; src/engine/lease.ts only injects `now`, not the timer, so I waited on the heartbeats instead.
- The container restarted once mid-run and lost background waits; commits survived. Chain the push to `make fast` in one background command.
