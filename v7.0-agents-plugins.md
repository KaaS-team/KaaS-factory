### #590 Agent presets become plugins

## Problem

Agent presets live in the core package. They should be plugins on the registry.

## Acceptance

- Each agent preset is a plugin that registers itself.
- The old core paths are removed and a test pins that they do not return.
- Behaviour for every preset is unchanged, proved by the existing tests.

## Out of scope

- The lwpr runtime and enterprise code.

Blocked by: #588

### #591 The lwpr runtime becomes a plugin

## Problem

The lwpr runtime is part of the core. It should be a plugin so the core runs without it.

## Acceptance

- The runtime registers through the registry.
- The core starts and passes its tests with the plugin disabled.
- A test fails if core code imports the plugin directly.

## Out of scope

- Other runtimes.

Blocked by: #588
