## Issues

### #67 Changelog and ADR as a workflow step

## Problem

A changelog entry and a decision record are workflow steps (PRs #499, #505, #539), but `factory install` only mentions the release workflow in text. A new repo ends up without it.

## Acceptance

- `factory init` writes the release workflow into the target repo.
- Running it twice changes nothing.
- A test covers a fresh repo and a repo that already has it.

## Out of scope

- Editing an existing release workflow.

### #68 Build refuses to run in workflows that have no plan step

## Problem

A workflow with no plan step cannot build: build refuses to run. Part is fixed (build can take its input from the triage output, PR #495), but no test runs every shipped workflow to prove each one can build.

## Acceptance

- A test loads every shipped workflow and proves each has a valid path to the build step.
- A workflow with a build step and no input source fails the test with its name.

## Out of scope

- Changing any shipped workflow.

### #349 Shared CI baseline for every KaaS-team repo

## Problem

Each KaaS-team repo carries its own CI settings, so a fix to one is not applied to the others. A baseline script and example workflow exist, but the shared workflow is not wired and the doctor does not fail when a repo drifts from it.

## Acceptance

- One reusable workflow defines the baseline checks, and each repo calls it.
- `factory doctor` fails and names the missing or drifted check when a repo does not call it.
- A test covers a repo that matches and one that drifts.

## Out of scope

- Repo-specific checks beyond the baseline.

### #262 Accept configurable event types and one signature header list

## Problem

The `events.accept` config key and the shared signature-header list are on main, but the event ingress still checks the old fixed list of event types. A sender whose type is listed in `events.accept` is ignored.

## Acceptance

- An event whose type matches `events.accept` is accepted at the ingress.
- With the key unset, the fixed list behaves exactly as today.
- A test covers an accepted and a refused type, and fails when the ingress ignores the key.

## Out of scope

- How events are signed, and the default list.
