### #65 QA step: exercise the change in a running app

## Problem

The QA step runs, but it does not start the application, so it cannot exercise a change in a running app. Visual and behaviour claims are then checked only against tests.

## Acceptance

- The QA step starts the app with the repo's own run command and waits until it answers.
- A failed start fails the step with the command's output.
- The app is stopped at the end whether the step passed or not.
- A test covers a start that succeeds, one that fails and one that never answers.

## Out of scope

- Which flows to exercise.
